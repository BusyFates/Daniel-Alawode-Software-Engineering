# 📊 BrawlStatz Analytics Dashboard

BrawlStatz is a web tool that tracks live Brawl Stars player statistics, evaluates practice efficiency, and analyzes character roster depth.

## 🚀 How to Run the App
This application requires absolutely no code installation, no computer terminal setup, and no dependencies to run. 

To launch the dashboard instantly from any computer, phone, or tablet device, simply click the public link below:

👉 **[Launch BrawlStatz Live Web App](daniel-alawode-software-engineering-dm2h2tqg5gwzioxebgjwiv.streamlit.app)**

---

## 📁 System Logging & Features
*   **Zero-Setup Data Fetching:** Type a player tag (such as `2J0YV80QU`) into the web interface to view real-time account parameters instantly.
*   **Automatic Progress Tracking:** The web platform records snapshot deltas locally to dynamically process daily metrics across lookup sessions.
*   **Built-in Network Protection:** If the system detects security restrictions or firewall blocks on your current Wi-Fi network, it automatically routes to a simulation fallback mode to keep the application active without crashing.
